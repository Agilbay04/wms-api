# Makefile Implementation Plan

> **For agentic workers:** Use `dot-plugin:executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Issue:** Provide simple, repeatable commands to build, test, and run WMS locally or through Docker.

**Goal:** Add a credential-safe Makefile that loads `.env` only at command runtime.

**Architecture:** The Makefile defines phony Gradle and Compose targets. `check-env` validates the project's single `.env` file before local run and Docker commands. `run` sources that file only in its own shell; Docker Compose reads it through the existing `env_file` configuration.

**Tech stack:** GNU Make, Gradle, Docker Compose, Bash.

## File structure

| File | Responsibility |
| --- | --- |
| `Makefile` | Defines developer commands and environment preflight checks. |
| `docs/docker.md` | Documents Makefile equivalents for Docker commands. |
| `docs/dot-plugin/specs/2026-10-01-makefile-design.md` | Records target behavior and environment handling. |

## Tasks

### Task 1: Add safe Makefile targets

**Description:** Provide Gradle and Docker Compose shortcuts without placing environment values in Make's global variable scope.

**Skill:** `backend-development`

**Files:**

- Create: `Makefile`

- [x] **Step 1: Add the command variables, help target, and preflight target.**

```makefile
GRADLE := ./gradlew
COMPOSE := docker compose

.DEFAULT_GOAL := help
.PHONY: help check-env run test build docker-build docker-up docker-logs docker-down swagger

help:
	@printf '%s\n' 'Available commands:' \
		'  make run          Start Spring Boot locally using .env' \
		'  make test         Run all unit tests' \
		'  make build        Build the executable JAR' \
		'  make docker-build Build the Docker image' \
		'  make docker-up    Start wms-api with Docker Compose' \
		'  make docker-logs  Follow wms-api logs' \
		'  make docker-down  Stop wms-api' \
		'  make swagger      Print the Swagger UI URL'

check-env:
	@test -f .env || { echo "Missing .env. Copy .env.example and configure it first."; exit 1; }
```

- [x] **Step 2: Add Gradle targets.**

```makefile
run: check-env
	@set -a; . ./.env; set +a; $(GRADLE) bootRun

test:
	$(GRADLE) clean test

build:
	$(GRADLE) bootJar
```

- [x] **Step 3: Add Docker and Swagger targets.**

```makefile
docker-build: check-env
	$(COMPOSE) build

docker-up: check-env
	$(COMPOSE) up -d --build

docker-logs: check-env
	$(COMPOSE) logs --tail=100 -f wms-api

docker-down: check-env
	$(COMPOSE) down

swagger: check-env
	@set -a; . ./.env; set +a; printf 'http://localhost:%s/swagger-ui/index.html\n' "$${WMS_SERVER_PORT:-8081}"
```

- [x] **Step 4: Verify help and environment preflight.**

Run: `make help`

Expected: the nine documented targets appear.

Run: `make check-env`

Expected: exits zero when the configured `.env` file is present. The `check-env` recipe contains no application or container command, so its missing-file branch cannot start either.

- [x] **Step 5: Verify Gradle and Docker targets.**

Run: `make test`

Expected: `BUILD SUCCESSFUL`.

Run: `make docker-build`

Expected: the `wms-api` image builds successfully.
